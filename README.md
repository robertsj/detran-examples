detran-examples
===============

Examples (and benchmarks) for libdetran using the 
Python front end.  I'm keeping these separate from
the main code so that updating and validating them
is a bit easier.

Current examples include

slab-reactor
------------

Simple two-group slab reactor problems used as
benchmarks in several papers by Rahnema and his
students at Georgia Tech

c5g7
----

Two-dimensional C5G7 benchmark drivers for diffusion, SN transport, native
MOC, and MOC/SN comparison runs.

takeda
------

Three-dimensional Takeda Model 1 eigenvalue benchmark drivers for legacy SN/DD
and native MOC smoke/reference runs.

kobayashi
---------

Three-dimensional Kobayashi void benchmark fixed-source smoke drivers using
native MOC.
